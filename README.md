# Herd Yard Cattle Co — website template

An all-in-one website for a cattle business: public site, client portal and farm admin dashboard. It's a single `index.html` with plain HTML, CSS and JavaScript, so there's no framework and no build step.

## View it

Open `index.html` in Chrome, Safari or Edge. To put it online, upload the file to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages). If the host asks for a framework, choose **simple folder of files / static** with no build command.

## Demo access

Go to **Client login**, then **Open the customer account** or **Open the farm admin dashboard**.

## What's included

- **Public pages:** Home, Live Cattle, Beef, Frozen Genetics, Bull Leases, Meet the Herd, Farm Journal, Life on the Farm, Events & Visits, Beef Buying Guide (with calculator), Recipes, Pickup & Delivery, Reviews, About, Contact, Client Login and Cart.
- **Herd Yard storefront:** the embed script (account 8688) loads on the Live Cattle, Beef, Frozen Genetics and Cart pages. Change it in the Website Editor under Herd Yard embed script.
- **Client portal:** order tracking with steps for each order type, messages, payments and invoices, documents, favorites and waitlists, profile and notifications.
- **Admin dashboard:** overview, orders, customer records (CRM), messages, calendar, bull leases, waitlists, herd profiles, farm journal, photo posting with rotation, recipes, delivery, reviews, marketing, analytics, website editor and integrations.
- **Website editor:** brand, header photos for every page, colours, fonts, announcement bar, homepage section order, menus, search titles and seasonal effects (snow, leaves, flowers and more) on a schedule.

## Limits of this build

This is a front-end prototype with sample data:

- Edits, photos and logins are saved only in each visitor's own browser.
- Google Business reviews, Gmail, Calendar, Maps and Analytics connections are simulated.
- A production version needs a back end, such as Next.js with Supabase, for secure logins, a database, photo storage and the Google sign-in connections.
